## How it works

Funciona mediante compuertas logicas nor, que solo retornan el valor de 1 cuando ambas entradas son igual a 0, luego como los nor son solo de 2 entradas usamos 4. Tuvimos que usar 3 and para que la unica posibilidad de que el ultimo and de 1 sea que el usuario ingrese todos 0.

## How to test

Apagar la entrada y apretar las veces necesarias el boton del step hasta que ningun flip flop tenga valor de 1, es decir, cuando se prende verde.
